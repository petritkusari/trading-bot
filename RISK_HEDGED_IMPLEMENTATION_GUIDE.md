## ⚠️ SAFETY PROTOCOLS - FOLLOW RELIGIOUSLY

### Daily Checks:

```
□ Check portfolio value
□ Calculate current drawdown
□ IF drawdown > -25%: STOP LOSS - EXIT ALL
□ IF any position down > -8%: EXIT THAT POSITION
□ Track every trade in spreadsheet
```

### Weekly Checks:

```
□ Review win/loss ratio (should be > 90%)
□ Check if strategies still working
□ Rebalance if positions > 10% off target
□ Review upcoming earnings (avoid trading during earnings)
```

### Monthly Reviews:

```
□ Calculate monthly return
□ Compare to expected (should average ~8-10%/month)
□ If underperforming 2 months straight: Reduce position size
□ If outperforming: Consider slightly increasing allocation
```

### Emergency Stops:

```
IMMEDIATELY EXIT ALL POSITIONS IF:
□ Portfolio down -25% (automatic stop-loss)
□ Major market event (9/11-style)
□ VIX spikes above 80 unexpectedly
□ You can't monitor positions for > 1 week
□ You're emotionally stressed/scared
```
